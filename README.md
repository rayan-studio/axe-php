# Dépendances

Pour utiliser le projet, les dépendances suivantes sont nécessaires :

* [Wampserver](https://wampserver.aviatechno.net/)
* [Node.js](https://nodejs.org/fr)

# Démarrer le projet

Le projet utilise **npm** pour lancer l'environnement de développement.

```bash
npm run dev
```
